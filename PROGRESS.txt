=== ЧТО ТАКОЕ ЭТОТ ПРОЕКТ ===

Python-система защиты персональных данных учеников в школе (Казахстан).
Два компонента:
  - agent/     → запускается на школьном ПК (ноутбук 2, Windows)
  - server/    → FastAPI-сервер + веб-дашборд (ноутбук 1)

GitHub: https://github.com/yErkaa/edr_project
Ноутбук 1 (сервер): C:\Users\dinar\PycharmProjects\edr\
Ноутбук 2 (агент):  C:\edr_agent\

Сервер слушает: http://DESKTOP-CLJB78R:8088  (имя компьютера, не меняется при смене сети)
Дашборд: http://127.0.0.1:8088  логин: admin  пароль: admin123
ВАЖНО: на ноутбуке 1 должно быть правило файрвола: порт 8088 открыт
  → netsh advfirewall firewall add rule name="EDR Server" dir=in action=allow protocol=TCP localport=8088
БД: PostgreSQL, база edr_school. Создать: python server/migrate.py

=== КАК ЗАПУСКАТЬ ===

Сервер:  cd server && uvicorn api:app --host 0.0.0.0 --port 8088
Агент:   cd agent  && python agent.py
Оба:     START_EDR.bat

=== СТРУКТУРА ПРОЕКТА ===

edr/
├── agent/
│   ├── agent.py            ← главный процесс агента
│   ├── pii_scanner.py      ← сканер ПД (ИИН, телефон, ФИО, email, дата рождения)
│   ├── quarantine.py       ← карантин файлов + DirectoryWatcher (ReadDirectoryChangesW)
│   ├── response_handler.py ← блокировки ACL, уведомления, мониторинг буфера обмена
│   ├── usb_monitor.py      ← мониторинг USB через psutil
│   ├── process_monitor.py  ← blacklist процессов (mimikatz, netcat, procdump)
│   ├── config.ini          ← настройки (НЕ в git — содержит пароль и IP)
│   ├── config.ini.example  ← шаблон конфига (в git)
│   └── requirements.txt
│
├── server/
│   ├── api.py              ← все REST-эндпоинты + WebSocket
│   ├── models.py           ← SQLAlchemy-модели (8 таблиц)
│   ├── db.py               ← подключение к PostgreSQL
│   ├── detection_engine.py ← правила генерации алертов
│   ├── migrate.py          ← создаёт таблицы в БД
│   └── templates/index.html← весь фронтенд (Bootstrap 5 + Chart.js)
│
├── installer_for_second_laptop/ ← установщик агента на второй ПК
├── attack_simulator.py     ← создаёт тестовые файлы с ПД для проверки
├── START_EDR.bat
└── run_agent.ps1           ← делает git pull + запускает агент с авторестартом
