==============================================
  EDR АГЕНТ — Инструкция установки на новый ноутбук
  (Работает для 2-го, 3-го, любого числа ноутбуков)
==============================================

ОБА ноутбука должны быть подключены к ОДНОЙ WiFi-сети!

──────────────────────────────────────────────
ШАГ 0: Установить Python (только если не установлен)
──────────────────────────────────────────────

  1. Открой браузер → https://www.python.org/downloads/
  2. Скачай Python 3.10 или новее
  3. При установке ОБЯЗАТЕЛЬНО поставь галочку:
     [x] Add Python to PATH
  4. Нажми Install Now
  5. После установки перезагрузи компьютер

  Проверить: откройте cmd и введите:  python --version
  Должно показать:  Python 3.x.x

──────────────────────────────────────────────
ШАГ 1: На первом ноутбуке (сервер)
──────────────────────────────────────────────

  1. Запусти START_EDR.bat (или START_SERVER_ONLY.bat)
  2. Дашборд: http://127.0.0.1:8088  (логин: admin)

  Узнай IP первого ноутбука — в cmd введи:
      ipconfig
  Ищи строку: IPv4-адрес . . . : 192.168.X.X

  Открой порт 8088 в Firewall (один раз, от администратора):
      netsh advfirewall firewall add rule name="EDR Server" dir=in action=allow protocol=TCP localport=8088

──────────────────────────────────────────────
ШАГ 2: На школьном ноутбуке (агент)
──────────────────────────────────────────────

  1. Скопируй папку installer_for_second_laptop на USB-флешку
  2. Перенеси флешку на школьный ноутбук
  3. Открой папку с флешки
  4. Правая кнопка на install.bat → "Запуск от имени администратора"
  5. Когда спросит IP сервера — введи IP первого ноутбука
     (например: 192.168.1.5)
  6. Установка займёт 3-10 минут (качает зависимости из интернета)
  7. Агент запустится автоматически

  Что происходит при установке:
  - Создаётся C:\EDR\agent\ с файлами агента
  - Устанавливаются Python-пакеты (requests, psutil, pywin32 и др.)
  - Создаётся config.ini с адресом сервера
  - На Рабочем столе появляется ярлык "EDR Agent.bat"

──────────────────────────────────────────────
ШАГ 3: Проверка что всё работает
──────────────────────────────────────────────

  На ПЕРВОМ ноутбуке открой: http://127.0.0.1:8088

  → Вкладка "Агенты" — должен появиться новый агент
    (имя = hostname школьного ноутбука)
    Статус: зелёный (онлайн)

  → Тест PII-детекции: на школьном ноутбуке создай файл
    test.txt на Рабочем столе со строкой:
        ИИН: 900101300017
    Сохрани. Через 5-10 секунд на дашборде → событие pii_detected

──────────────────────────────────────────────
КАК ЗАПУСКАТЬ АГЕНТ В СЛЕДУЮЩИЙ РАЗ
──────────────────────────────────────────────

  Способ 1: Рабочий стол → "EDR Agent.bat"
            (правая кнопка → "Запуск от имени администратора")

  Способ 2: cmd от администратора:
            cd C:\EDR\agent
            call START_AGENT.bat

  При каждом запуске агент:
  - Проверяет обновления на сервере (auto-update)
  - Регистрируется и появляется в дашборде
  - Сканирует Desktop, Documents, Downloads

──────────────────────────────────────────────
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
──────────────────────────────────────────────

  "Python не установлен"
    → Установи Python (Шаг 0), поставь галочку Add to PATH

  "Сервер недоступен" / "Connection refused"
    → Проверь что на первом ноутбуке запущен START_EDR.bat
    → Оба ноутбука в одной WiFi-сети?
    → Порт 8088 открыт в Firewall? (команда из Шага 1)

  "Агент не видно в дашборде"
    → Подожди 30 секунд после запуска
    → Проверь лог: C:\EDR\agent\logs\agent.log

  "Ошибка при установке пакетов"
    → Нужен интернет при установке
    → Попробуй запустить install.bat ещё раз
