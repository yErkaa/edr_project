==============================================
  EDR АГЕНТ — Инструкция для второго ноутбука
==============================================

Оба ноутбука должны быть подключены к ОДНОЙ WiFi-сети!

──────────────────────────────────────────────
ШАГ 1: На ТВОЁМ ноутбуке (сервер — 192.168.0.3)
──────────────────────────────────────────────

  1. Запусти START_SERVER_ONLY.bat (или полный START_EDR.bat)
  2. Убедись что сервер работает: открой браузер и зайди на
     http://127.0.0.1:8088
     (должен открыться дашборд EDR, логин: admin / пароль: admin123)
  3. Твой IP в сети: 192.168.0.3

  ОТКРОЙ ПОРТ В FIREWALL (выполни один раз от администратора):
  Нажми Win+R → cmd → Запуск от имени администратора → вставь:

  netsh advfirewall firewall add rule name="EDR Server" dir=in action=allow protocol=TCP localport=8088

──────────────────────────────────────────────
ШАГ 2: На ВТОРОМ ноутбуке (школьный ПК)
──────────────────────────────────────────────

  1. Скопируй папку installer_for_second_laptop на флешку
  2. Перенеси флешку на второй ноутбук
  3. Открой папку с флешки
  4. Правая кнопка мыши на install.bat →
     "Запуск от имени администратора"
  5. Когда спросит "IP сервера" — введи: 192.168.0.3
  6. Установка займёт 3-5 минут (скачает зависимости)
  7. Агент запустится автоматически

──────────────────────────────────────────────
ШАГ 3: Проверка что всё работает
──────────────────────────────────────────────

  На твоём ноутбуке открой: http://127.0.0.1:8088

  → Вкладка "Агенты" — должен появиться второй агент
    (имя = hostname второго ноутбука)

  → Тест: на втором ноутбуке создай файл test.txt
    со строкой вида: 020512550123 (12-значный ИИН)
    Сохрани на Рабочий стол.
    Через 5-10 секунд на дашборде появится событие pii_detected.

──────────────────────────────────────────────
НОВЫЕ ФУНКЦИИ ДАШБОРДА
──────────────────────────────────────────────

  С главного ноутбука можно управлять файлами на втором:

  → Вкладка "ПД-Файлы":
    • Поле "Поиск по списку" — мгновенно фильтрует таблицу
    • Кнопка "Поиск на дисках" — вводишь имя файла (или часть),
      агент ищет на дисках C: и D: и проверяет наличие ПД
    • Кнопка "Карантин" — переместить файл на компьютере ученика

  → Вкладка "Карантин":
    • Все файлы в карантине с кнопкой "Восстановить"

  → Поддерживаемые типы файлов:
    .docx .xlsx .pptx .pdf .txt .jpg .jpeg .png .bmp .tiff

──────────────────────────────────────────────
КАК ЗАПУСКАТЬ АГЕНТ В СЛЕДУЮЩИЙ РАЗ
──────────────────────────────────────────────

  На втором ноутбуке, после установки:

  Способ 1 (ярлык):
    Рабочий стол → "EDR Agent.bat" (создаётся при установке)

  Способ 2 (вручную):
    Открой cmd от администратора:
    cd C:\EDR\agent
    python agent.py

──────────────────────────────────────────────
ВАЖНЫЕ АДРЕСА И ФАЙЛЫ
──────────────────────────────────────────────

  Дашборд:           http://192.168.0.3:8088
  Логин / пароль:    admin / admin123
  Агент установлен:  C:\EDR\agent\
  Лог агента:        C:\EDR\agent\logs\agent.log
  Настройки:         C:\EDR\agent\config.ini
  Карантин:          C:\EDR_Quarantine\

──────────────────────────────────────────────
ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
──────────────────────────────────────────────

  Проблема: "Сервер недоступен"
    → Убедись что оба ноутбука в одной WiFi
    → Убедись что на первом ноутбуке запущен сервер
    → Проверь что порт 8088 открыт в Firewall (шаг 1)

  Проблема: Агент не видит файлы
    → Агент мониторит: Desktop, Documents, Downloads
    → Поддерживаемые форматы: .docx .xlsx .pptx .pdf .txt
      .jpg .jpeg .png .bmp .tiff (изображения со сканом)

  Проблема: Агент падает при старте
    → Открой C:\EDR\agent\logs\agent.log — там текст ошибки
    → Проверь что Python установлен: python --version
