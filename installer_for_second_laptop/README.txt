====================================================
  EDR АГЕНТ — Полностью автоматическая установка
====================================================

  Нужен только интернет и права администратора.
  Python устанавливается сам если его нет.

──────────────────────────────────────
 КАК УСТАНОВИТЬ
──────────────────────────────────────

  1. Скопируй папку installer_for_second_laptop на USB
  2. Перенеси на новый ноутбук
  3. Правая кнопка на install.bat →
     "Запуск от имени администратора"
  4. Готово. Ждёшь 5-15 минут.

  Всё устанавливается само:
  - Python 3.12 (если не установлен)
  - Все зависимости
  - Агент в C:\EDR\agent
  - Ярлык на Рабочем столе

──────────────────────────────────────
 ЕСЛИ СПРОСИТ О ПЕРЕЗАГРУЗКЕ
──────────────────────────────────────

  Иногда после установки Python нужна перезагрузка.
  Перезагрузи и запусти install.bat снова — он
  продолжит с того места где остановился.

──────────────────────────────────────
 СЛЕДУЮЩИЕ ЗАПУСКИ
──────────────────────────────────────

  Рабочий стол → ПКМ на "EDR Agent.bat" →
  "Запуск от имени администратора"

──────────────────────────────────────
 ПРОВЕРКА
──────────────────────────────────────

  На первом ноутбуке: http://127.0.0.1:8088
  Вкладка "Агенты" → новый агент (зелёный статус)

──────────────────────────────────────
 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
──────────────────────────────────────

  Лог: C:\EDR\agent\logs\agent.log

  Нет интернета при установке:
   → Без интернета Python не скачается.
   → Установи Python вручную: python.org/downloads
     (при установке: галочка "Add Python to PATH")
   → Потом снова запусти install.bat

  Сервер недоступен:
   → Запусти START_EDR.bat на первом ноутбуке
   → Оба ноутбука в одной WiFi?
   → Открыть порт (на первом ноутбуке, от администратора):
     netsh advfirewall firewall add rule name="EDR" dir=in action=allow protocol=TCP localport=8088
