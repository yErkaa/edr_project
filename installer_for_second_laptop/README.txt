====================================================
  EDR АГЕНТ — Установка одной кнопкой
  Сервер: DESKTOP-CLJB78R (первый ноутбук)
====================================================

ТРЕБОВАНИЯ:
  - Ноутбук подключён к той же WiFi что и сервер
  - Python 3.10+ установлен (см. ниже если нет)

──────────────────────────────────────
 КАК УСТАНОВИТЬ
──────────────────────────────────────

  1. Скопируй папку installer_for_second_laptop на USB-флешку
  2. Перенеси на новый ноутбук
  3. Правая кнопка на install.bat →
     "Запуск от имени администратора"
  4. Всё! Ждёшь 5-10 минут — агент запустится сам.

  Никаких вопросов и настроек — только одна кнопка.

──────────────────────────────────────
 ЕСЛИ PYTHON НЕ УСТАНОВЛЕН
──────────────────────────────────────

  install.bat сам скажет если Python нужно установить.

  Установка Python (один раз):
  1. https://www.python.org/downloads/
  2. Скачать Python 3.10 или новее
  3. При установке: поставить галочку "Add Python to PATH"
  4. Перезагрузить ноутбук
  5. Запустить install.bat снова

──────────────────────────────────────
 ПРОВЕРКА
──────────────────────────────────────

  На первом ноутбуке открой:
  http://127.0.0.1:8088

  Вкладка "Агенты" → должен появиться новый агент
  (имя = hostname нового ноутбука, зелёный статус)

──────────────────────────────────────
 СЛЕДУЮЩИЕ ЗАПУСКИ
──────────────────────────────────────

  Рабочий стол → "EDR Agent.bat"
  (правая кнопка → Запуск от имени администратора)

  При каждом запуске агент сам проверяет обновления.

──────────────────────────────────────
 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
──────────────────────────────────────

  Лог агента: C:\EDR\agent\logs\agent.log

  "Сервер недоступен":
   → Запусти START_EDR.bat на первом ноутбуке
   → Оба ноутбука в одной WiFi?

  Открыть порт на первом ноутбуке (один раз):
   netsh advfirewall firewall add rule name="EDR" dir=in action=allow protocol=TCP localport=8088
