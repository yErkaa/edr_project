============================================
  EDR Agent — Установщик v2 (без настройки)
============================================

КАК ПОЛЬЗОВАТЬСЯ
────────────────

Шаг 1 (один раз на твоём ноутбуке):
  Запусти BUILD_INSTALLER.bat из корня проекта
  Он сам скачает Python и подготовит эту папку.

Шаг 2 (для каждого нового ноутбука):
  1. Скопируй папку installer_v2 на флешку
  2. Открой флешку на нужном ноутбуке
  3. Двойной клик на START.bat
  4. Готово — агент работает!

ЧТО ПРОИСХОДИТ ПРИ ЗАПУСКЕ START.bat
──────────────────────────────────────
  • Создаёт C:\EDR_Quarantine\  (папка карантина)
  • Копирует файлы агента в C:\EDR\agent\
  • Запускает агент через встроенный Python
  • Агент подключается к серверу DESKTOP-CLJB78R:8088

НА ЦЕЛЕВОМ НОУТБУКЕ НЕ НУЖНО:
  ✗ Устанавливать Python
  ✗ Запускать pip install
  ✗ Вводить IP или hostname сервера
  ✗ Выходить в интернет

ТРЕБОВАНИЯ К ЦЕЛЕВОМУ НОУТБУКУ:
  ✓ Windows 10/11 (64-bit)
  ✓ Та же WiFi-сеть что и сервер
  ✓ Ноутбук с сервером называется DESKTOP-CLJB78R

КАК ЗАПУСКАТЬ АГЕНТ В СЛЕДУЮЩИЙ РАЗ:
  Способ 1: флешка → START.bat (двойной клик)
  Способ 2: C:\EDR\agent\ → "EDR Agent.bat" на рабочем столе
